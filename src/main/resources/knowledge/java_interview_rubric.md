# 大厂后端面试评分标准（Java 高级工程师）

> 本文档用于 RAG 检索增强：系统会根据简历内容与用户提问，自动召回下方最相关的评分标准片段，作为模型进行简历诊断与模拟面试提问的唯一评分依据。

## 一、微服务架构治理

### 考察点
- 服务拆分原则与边界（DDD 限界上下文、按业务能力拆分、避免过度拆分）
- 注册中心与配置中心（Nacos / Eureka / Consul）的高可用与容灾
- 服务间通信选型：RPC（Dubbo / gRPC）与 HTTP（Feign / RestTemplate）的取舍
- 服务治理：熔断、限流、降级、超时、重试（Sentinel / Hystrix / Resilience4j）
- 分布式链路追踪（SkyWalking / Zipkin）与统一日志治理
- API 网关（Spring Cloud Gateway）的鉴权、路由、限流、灰度发布

### 深挖连环炮
1. 你们公司服务是怎么拆分的？拆得过细会带来什么问题？
2. 服务雪崩是怎么发生的？熔断、隔离、限流分别怎么避免？
3. 限流算法有哪些（固定窗口 / 滑动窗口 / 漏桶 / 令牌桶）？Sentinel 默认用哪种？
4. 分布式事务怎么处理？Seata 的 AT / TCC / SAGA 模式有什么区别与适用场景？
5. 请求从网关进来的完整链路是怎样的？网关如何做鉴权和限流？

### 高分回答标准
- 能结合真实项目讲清拆分演进过程与踩坑，而非背诵概念
- 能说出各治理组件的取舍，例如 Feign 超时与重试叠加导致的请求放大问题
- 对限流 / 熔断算法有原理级理解，能画出令牌桶 / 滑动窗口
- 分布式事务能横向对比多种方案，并说明最终一致性取舍

## 二、Redis 缓存高可用与一致性

### 考察点
- Redis 常用数据结构与底层实现（SDS / ziplist / quicklist / skiplist）
- 持久化机制：RDB vs AOF 及混合持久化
- 高可用架构：主从复制、哨兵（Sentinel）、Cluster 分片（16384 槽、moved / ask 重定向）
- 缓存三大问题：穿透、击穿、雪崩及对应解决方案
- 缓存与数据库一致性（Cache Aside、延迟双删、Canal + MQ 异步同步）
- 淘汰策略（LRU / LFU）与过期策略（惰性删除 + 定期删除）

### 深挖连环炮
1. 缓存穿透、击穿、雪崩有什么区别？分别怎么解决？
2. Redis Cluster 的槽是怎么分配的？扩容时数据如何迁移？
3. 主从复制是同步还是异步？主从切换会丢数据吗？
4. 为什么 Redis 单线程还这么快？6.0 之后的多线程做了什么？
5. 缓存和数据库双写不一致怎么解决？延迟双删为什么要“延迟”？

### 高分回答标准
- 三大问题能分别举出生产案例与具体参数（如布隆过滤器误判率）
- 能讲清 Cluster 的 slot 迁移与客户端重定向机制
- 对持久化与主从切换的数据丢失风险有清晰认知
- 一致性问题能给出多种方案，并对比强一致与最终一致

## 三、消息队列积压与幂等

### 考察点
- 主流 MQ 对比与选型（Kafka / RocketMQ / RabbitMQ）
- 消息可靠性：生产端确认、Broker 持久化、消费端 ACK
- 消息幂等：唯一 ID + 去重表、数据库唯一索引、Redis setnx
- 顺序消息与乱序处理、分区有序与全局有序
- 消息积压的处理与快速恢复
- 死信队列与消费失败重试机制

### 深挖连环炮
1. 消息积压到几百万条怎么处理？先救消费者还是先扩容？
2. 消费者怎么保证幂等？并发下唯一 ID 去重怎么做？
3. Kafka 为什么吞吐量高？零拷贝和顺序写讲一下？
4. 消息丢了怎么排查？生产端、Broker、消费端分别怎么保证？
5. 如何保证消息顺序消费？分区有序和全局有序怎么选？

### 高分回答标准
- 能给出积压的完整应急预案（先扩容消费者、批量消费、临时降级）
- 幂等方案能落地（唯一索引 / Redis 原子操作 / 去重表），并懂并发竞态
- 理解 Kafka 高吞吐原理（顺序写、零拷贝、分区并行）
- 可靠性从生产端、Broker、消费端三环节闭环，能画出消息流转图

## 四、JVM 内存调优

### 考察点
- JVM 内存区域划分（堆 / 栈 / 元空间 / 直接内存）
- 对象创建与内存分配（TLAB、逃逸分析、栈上分配）
- 垃圾回收算法与收集器（CMS / G1 / ZGC）
- 常见 OOM 类型与排查（heap / metaspace / direct memory）
- 调优工具链（jps / jstat / jmap / jstack / arthas / MAT）
- 调优思路与关键参数（-Xms / -Xmx / -XX:MaxMetaspaceSize 等）

### 深挖连环炮
1. G1 和 CMS 有什么区别？G1 为什么能取代 CMS？
2. 线上频繁 Full GC 怎么排查和优化？
3. 对象什么时候会进入老年代？大对象是怎么分配的？
4. 内存泄漏怎么排查？arthas 和 MAT 分别怎么用？
5. ZGC 的染色指针是什么？为什么停顿时间能做到 10ms 内？

### 高分回答标准
- 能结合 GC 日志分析停顿原因，并给出参数调整方案
- 理解分代回收与对象晋升机制，能解释大对象分配与 OOM
- 掌握至少一套完整排查工具链，并能讲出真实调优案例
- 对 G1 / ZGC 的算法演进有原理级理解
